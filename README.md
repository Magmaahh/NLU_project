# NLU Project Course
This repository contains the project developed for the 2024/2025 **Natural Language Understanding (NLU)** course offered by the **University of Trento**. 

## Table of Contents

- [Project Structure](#project-structure)
- [Setup](#setup)
- [Author](#author)

## Project structure
The project is organized into two main parts, each contained in a dedicated folder: 
- **LM** (Language Modeling) 
- **NLU** (Natural Language Understanding)

Each of these folders contains two sub-folders, one for part A and one for part B, and a detailed report with implementation details and results.
Inside each sub-folder, a README file with instructions is included.

```
project-root/ 
├── LM/
├──── part_A/
└──── part_B/
├── NLU/
├──── part_A/
└──── part_B/
```

## Setup
In order to run the project:
- Clone the repository:

    ```BASH
    git clone https://github.com/Magmaahh/NLU_project.git
    ```
- Inside the project's folder, create and activate the Conda environment:

    ```bash
    conda env create -f environment.yml -n nlu25
    conda activate nlu25
    ``` 

Then, follow the instructions in the dedicated README files of each sub-folder to proceed.
